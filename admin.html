Connect this device

Paste your GitHub access key below. It is saved only on this device and is never shown to anyone. Make one like this:

  1. On GitHub: your picture → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Name: Results admin. Expiration: up to 1 year.
  3. Repository access: Only select repositories → Missing-Numbers-Lotto.
  4. Permissions → Repository permissions → Contents: Read and write. Nothing else.
  5. Click Generate token, copy it, paste it here.
